# 런메이트 브랜드 콘텐츠 가이드

상태: 브랜드 소개·원본 카드뉴스 및 사용자 답변 반영. 직접 검색·서비스 내 참여 신청·인스타그램 프로필 링크 경로 확인 완료. 실제 URL과 계정명은 미제공.

## 1. 근거와 적용 범위

- 사용자 제공 소개: “런메이트는 내 주변에서 나와 페이스가 맞는 사람을 찾아 부담 없이 함께 달리는 가상의 러닝 커뮤니티입니다.”
- [원본 Figma 카드뉴스](https://www.figma.com/design/1D7Jqr9ku3boaa7GVbeAUm/?node-id=229-248): 해당 섹션의 상단 카드 5장과 하단 변형 카드 4장을 브라우저에서 열람했다. Figma 원본은 수정하지 않았다.
- 아래에서 **확정**은 사용자 소개와 후속 답변으로 확인된 브랜드 설정, **원본 표현**은 카드에 등장한 문구, **운영 제안**은 이를 바탕으로 도출한 콘텐츠 작성 기준이다.
- 원본에 기능처럼 보이는 문구가 있더라도 실제 제공 기능의 증거로 취급하지 않는다. 가상 브랜드를 실제 운영·출시된 서비스로 소개하지 않는다.

## 2. 브랜드 정의

**확정:** 런메이트는 가까운 곳에서 나와 페이스가 맞는 사람을 찾아, 부담 없이 함께 달리는 가상의 러닝 커뮤니티다.

**핵심 가치:** 가까움 · 나에게 맞는 페이스 · 편안한 동행.

**운영 제안:** 더 빠른 기록이나 경쟁보다, 함께 달릴 사람을 만나 가볍게 시작하는 경험에 초점을 맞춘다.

## 3. 대상

아래 대상은 소개와 원본 문구에서 도출한 콘텐츠 타깃이며, 실제 이용자 조사 결과는 아니다.

| 대상 | 느끼는 상황·욕구 | 콘텐츠가 전달할 가치 |
| --- | --- | --- |
| 혼자 달리는 것이 심심한 러너 | 같이 달릴 사람이 있으면 좋겠다 | 함께 달리는 즐거움 |
| 멀리 이동하지 않고 달리고 싶은 사람 | 동네에서 가볍게 시작하고 싶다 | 가까운 곳에서의 러닝 |
| 다른 사람의 속도를 따라가는 것이 부담스러운 사람 | 내 페이스에 맞춰 달리고 싶다 | 속도가 맞는 편안한 동행 |

연령, 성별, 거주 도시, 숙련도를 특정하지 않는다. 초보자의 공감을 유도할 수는 있지만, 초보 전용 서비스나 코칭 제공을 주장하지 않는다.

## 4. 핵심 메시지

**대표 메시지 — 운영 제안:** “내 주변에서, 내 페이스에 맞는 사람들과 부담 없이 함께 달려요.”

| 메시지 축 | 원본 표현 | 작성 방향 |
| --- | --- | --- |
| 함께 달리는 즐거움 | “혼자 뛰기 심심한 날 런메이트를 찾아요” | 일상적인 감정에 공감하며 시작한다 |
| 가까운 시작 | “우리 동네에서 가볍게 시작해요” | 거리와 시작의 부담을 낮춘다 |
| 맞는 페이스 | “속도가 맞으면, 함께 달리기 쉬워요” | 타인과의 비교보다 나에게 맞는 속도를 강조한다 |
| 함께한 경험 | “기록보다 오래 남는 건, 함께 달린 순간” | 성과 보장 대신 동행의 가치를 전한다 |
| 다음 행동으로 초대 | “다음 러닝은, 함께해요.” | 강요하지 않고 가볍게 제안한다 |

**확정 기능:** 지역·페이스별로 모임을 직접 검색하고, 서비스 안에서 참여 신청할 수 있다. “지역과 페이스로 모임을 찾아요”, “마음에 드는 모임에 참여 신청해요”를 사용할 수 있다. 자동 매칭으로 표현하지 않는다. GPS 탐색, 상세 필터 UI, 추천 알고리즘 등 확인되지 않은 작동 방식은 붙이지 않는다.

## 5. 말투

**원본 관찰:** 짧고 다정한 해요체. “찾아요”, “시작해요”, “쉬워요”, “함께해요”처럼 쉬운 일상어로 말을 건다.

**운영 제안:**

- 옆에서 함께 달릴 동료처럼 편안하게 말한다.
- “우리 동네”, “내 페이스”, “가볍게”, “함께”를 자연스럽게 사용한다.
- 한 카드에는 하나의 메시지를 담고, 제목은 짧게 끊는다.
- 감정에 공감한 뒤 작은 행동을 제안한다. 조급함이나 죄책감을 유도하지 않는다.
- 과장된 감탄, 과도한 이모지, 전문 러닝 용어는 줄인다.
- “무조건”, “완벽한”, “100%”, “누구나 기록 향상”처럼 보장하는 표현을 쓰지 않는다.

| 권장 예시 — 새로 작성한 문구 | 피할 예시 | 이유 |
| --- | --- | --- |
| “혼자 달리기 심심한 날, 함께 달려볼까요?” | “아직도 혼자 뛰세요?” | 독자의 선택을 깎아내리지 않는다 |
| “내 페이스로, 함께 달려요.” | “뒤처지지 말고 따라오세요!” | 속도 경쟁과 압박을 만들지 않는다 |
| “우리 동네에서 가볍게 시작해요.” | “AI가 완벽한 러닝 파트너를 즉시 매칭!” | 미확인 기능과 성능을 주장하지 않는다 |

## 6. CTA

**원본 CTA:** “내 주변 러닝 모임 찾기”  
**원본 마무리 메시지:** “다음 러닝은, 함께해요.”

| 용도 | 문구 | 사용 조건 |
| --- | --- | --- |
| 브랜드 초대 | “다음 러닝은, 함께해요.” | 가상 브랜드의 메시지로 사용 가능 |
| 서비스 탐색 전환 | “내 주변 러닝 모임 찾기” | 인스타그램 프로필 링크로 안내한다. 직접 링크 삽입 시에는 실제 URL이 필요하다 |
| 인스타그램 안내 — 운영 제안 | “프로필 링크에서 내 주변 러닝 모임을 찾아요.” | 프로필에 연결할 주소가 있다는 사용자 확인에 근거한다. 게시 전 링크가 등록되어 있는지 확인한다 |
| 소셜 콘텐츠 반응 유도 — 운영 제안 | “함께 달리고 싶은 친구에게 공유해요.” | 공유 가능한 게시 채널에서 사용 |

- 게시물마다 주된 CTA는 하나만 선택한다.
- CTA 경로: **인스타그램 프로필 링크 → 모임 탐색**. 사용자가 프로필에 연결할 주소가 있다고 확인했다. 실제 URL·계정명과 현재 프로필 등록 여부는 미확인이다. URL, 앱스토어 주소, 계정명, 프로필 링크를 만들어 넣지 않는다.
- 모임 참여 신청은 서비스 내에서 가능하다. 신청 즉시 참여 확정, 자동 승인 등의 세부 절차는 주장하지 않는다.
- 가입, 앱 다운로드, 무료 체험, 선착순 모집은 해당 경로·조건 확인 전까지 사용하지 않는다.
- 연결 경로가 없는 콘셉트 시안에는 작동하는 서비스 버튼처럼 안내하지 말고, 시안임을 명확히 한다.

## 7. 기능 확인 기록과 남은 정보

확인일: 2026-09-29. 아래 확정 내용의 근거는 사용자 후속 답변이다.

| 항목 | 확인된 내용 | 남은 정보·표현 제한 |
| --- | --- | --- |
| 지역·페이스별 모임 찾기 | 직접 검색 방식 | 자동 매칭으로 표현하지 않는다. 상세 검색 UI는 미확인 |
| 모임 참여 | 서비스 안에서 참여 신청 가능 | 승인 방식과 참여 확정 조건은 미확인 |
| CTA 연결 경로 | 인스타그램 프로필에 연결할 주소가 있음 | 실제 URL·계정명 미제공. 링크 삽입이 필요한 작업에서 요청한다. 현재 프로필 등록 여부는 게시 전 확인 |

AI 추천, 실시간 위치 추적, 채팅, 러닝 기록 측정, 코스 추천, 코칭, 신원 인증, 안전 보장, 이용료·무료 여부, 운영 지역·시간, 사용자 수와 성과 수치는 근거가 없다. 관련 콘텐츠가 필요해질 때 확인하고, 답변 전에는 사실처럼 쓰지 않는다.

## 8. 콘텐츠 자동화 적용 규칙

1. 사용자 소개와 후속 답변으로 확정된 설정을 기준으로 콘텐츠를 작성한다.
2. 원본 문구와 새로 작성한 문구를 구분한다. 원본의 기능성 표현을 검증된 사양으로 승격하지 않는다.
3. 기본 흐름은 **상황 공감 → 가까움·맞는 페이스의 가치 → 함께하는 경험 → CTA 하나**로 잡는다. 장수는 주제에 맞춘다.
4. 타깃의 연령·지역, 기능, 가격, 이용 조건, 후기와 수치를 임의로 추가하지 않는다.
5. 미확인 정보가 필요하면 초안에 `[확인 필요: 항목]`을 표시하고 사용자에게 질문한다. 표시가 남은 초안은 게시용 완성본으로 취급하지 않는다.
6. 기능이 확정되면 이 문서의 미확인 항목에 답변과 확인일을 기록하고, 허용 문구 및 CTA 조건을 갱신한다.
7. 원본 Figma는 참조 자료로만 사용한다. 콘텐츠 생성이나 문서 갱신을 이유로 원본을 수정하지 않는다.
