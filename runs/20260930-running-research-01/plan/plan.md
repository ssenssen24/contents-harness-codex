## 사진 제작 방향

사진 스타일은 프로젝트의 brand.md·content-design.md를 우선합니다. 아래는 이번 기획의 장면과 구도입니다.

### c01

기획 목적: 나란히 달리는 관계로 편안한 동행 표현 / 장소: 특정 지역을 식별할 수 없는 동네 공원 길 / 인원·행동: 성인 두 사람이 나란히 가볍게 달리는 뒷모습 / 감정: 여유와 친근함 / 빛·색감: brand.md와 content-design.md의 사진 기준 우선 / 구도: 두 사람을 중경에 놓고 같은 방향으로 이어지는 길을 남김 / 텍스트 여백: 하단 왼쪽의 단순한 길 영역 / 최종 크롭: 4:5 풀 사진, 두 사람의 관계와 발끝을 보존 / 피할 요소: 경쟁 구도·결승선·식별 가능한 랜드마크·타 브랜드 로고·사진에 생성된 글자. 기획 승인 후 신규 생성.

### c02

사진 없음. 독자의 감정을 짧은 문장으로 읽는 쉼표 역할이므로 타이포그래피 중심으로 구성한다.

### c03

기획 목적: 함께 달리는 편안한 리듬을 디테일로 표현 / 장소: 표지와 같은 분위기의 공원 길 / 인원·행동: 두 성인 러너의 하체와 자연스러운 보폭 / 감정: 편안한 동행 / 빛·색감: 두 기준 문서 우선, 표지와 일관된 중성색 운동복 / 구도: 옆뒤에서 본 두 사람의 다리와 신발, 진행 방향 앞쪽에 여유 / 텍스트 여백: 사진 위 별도 제목 영역을 사용할 예정 / 최종 크롭: 카드 하단 가로 사진 영역, 두 사람의 발과 발끝을 보존 / 피할 요소: 과장된 속도 효과·비정상 관절·복제된 신발·브랜드 로고·텍스트. 표지 사진을 잘라 대체하지 않고 신규 생성.

### c04

기획 목적: 일상 가까이에서 함께 달리는 장면을 보여줌 / 장소: 특정 도시를 식별할 수 없는 나무와 산책로가 있는 공원 / 인원·행동: 성인 두 사람이 같은 방향으로 가볍게 달리는 넓은 장면 / 감정: 가까움과 부담 없는 시작 / 빛·색감: 두 기준 문서의 사진 기준과 앞선 사진의 톤 유지 / 구도: 인물은 오른쪽 중하단, 왼쪽에 단순한 배경 여백 / 텍스트 여백: 왼쪽 상단과 중앙 / 최종 크롭: 4:5, 두 사람과 길의 맥락을 함께 보존 / 피할 요소: 지도핀·실제 모임명·장소명·앱 화면·추천 매칭 표현·사진 내 글자. 별도 신규 생성.

### c05

사진 없음. 마지막 행동 하나가 먼저 읽히도록 여백과 저장된 벡터 자산으로 마무리한다.

## 캡션

> 누군가와 함께 달리고 싶지만, 속도를 따라가야 할까 망설여지는 날이 있어요.
> 
> 내게 편안한 페이스를 기준으로, 가까운 곳에서 함께 달릴 모임을 찾아보는 건 어떨까요? 런메이트에서는 지역과 페이스로 모임을 직접 검색할 수 있어요.
> 
> 프로필 링크에서 내 주변 러닝 모임을 찾아요.
> 
> 런메이트는 가상의 러닝 커뮤니티이며, 이 콘텐츠는 브랜드 콘셉트 시안입니다.

## 확인 사항

- **확인:** 사용자 선택 주제는 “함께 달려도, 내 페이스는 그대로”. 서비스 기능·CTA는 [brand.md](../../../brand.md)의 확인 범위를 따른다.
- **관찰:** n027의 제목과 장면, a016의 디테일 컷, a011·a060의 장소 표현을 참고했다. [조사 보고서](../research/research.md)와 [출처 기록](../research/sources.json)에 근거가 있다.
- **제안:** 5장 흐름·문구·사진 브리프·레이아웃은 이번 기획의 제안이며 브랜드 공식 규정이나 성과 보장이 아니다.
- **미확인:** 실제 서비스 URL·계정명·프로필 등록 여부. 임의 링크나 미확인 기능을 추가하지 않는다. 경쟁사 순위는 확인한 게시물 중 순위이며 전체 Top 6는 미확정이다.
- **사진 검토:** 원본 카드 분위기는 [content-design.md](../../../content-design.md)를 따른다. 같은 기획의 모델·의상 연속성, 자연스러운 보폭·손발, 크롭·여백·가독성을 사람이 확인한다. 실제 수정 프리뷰 v002에서는 사용자 피드백에 따라 c04를 c01·c03과 이어지는 인물로 맞췄다.
- **자동 검사:** 표·사진 방향·캡션과 하단 데이터 일치, 5장·1080×1350, ID·순서·문구·출처·CTA 하나. 사실 진위·말투·시각 완성도는 사람 판단이다.
- **승인 이력:** 기획 v001과 프리뷰 v002는 승인되어 제작 완료되었다. 이번 문서는 동일한 제작 데이터를 사람이 읽기 좋게 재구성한 열람본이다. [승인 당시 원문](archive/v001.md)과 기존 승인 기록을 보존했다. 새 기획 승인 요청이 아니다.
