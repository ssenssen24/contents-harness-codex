# 콘텐츠 기획 v001 — 함께 달려도, 내 페이스는 그대로

실행 ID: `20260930-running-research-01`  
상태: 사용자 기획 승인 대기. 주제 선택은 완료했으며 제작 승인은 아직 받지 않았다.

## 기준과 근거

- 기준: [brand.md](../../../brand.md), [content-design.md](../../../content-design.md). 색·서체·사진 스타일·재사용 자산의 규정과 값은 해당 문서를 직접 참조한다.
- 조사: [research.md](../research/research.md), [sources.json](../research/sources.json). 확인한 게시물 중 순위이며 전체 인기 Top 6가 아니다. 이 주제의 성과를 검증한 조사도 아니다.
- 사용자 확인: “1번 주제로 해줘”로 첫 번째 후보를 선택했다. 아래의 장수·문구·장면·구성은 Codex가 제안한 승인 대상이다.
- 사실 근거: 기능 문구와 CTA 경로는 brand.md의 확정 범위에서만 작성했다. 연구 출처 ID는 시각적 전달 방식의 참고이며 서비스 기능이나 독자 심리를 입증하는 출처가 아니다.

## 구성 제안과 선택 이유

5장으로 제안한다. 표지 → 속도 부담에 대한 공감 → 맞는 페이스의 동행 → 모임 탐색 기능 → CTA 순서다. 각 카드에 하나의 역할을 주고, 사진 3장과 무사진 2장을 교차해 읽는 리듬을 만든다. 장수는 이번 주제를 위한 제안이며 원본 템플릿의 고정 장수가 아니다.

대상은 기준 문서의 세 대상 중 속도 부담을 느끼는 사람 하나로 좁혔다. 연령·성별·숙련도·도시는 타깃 조건으로 추가하지 않는다. 표지의 표현은 내게 맞는 동행을 선택하자는 메시지이며 일정한 속도나 매칭 결과의 보장이 아니다.

경쟁사의 색·서체·극적인 스포츠 사진을 스타일 기준으로 가져오지 않는다. 신규 사진은 두 기준 문서의 원본 카드뉴스 분위기를 우선하고, 아래 브리프는 그 범위 안에서 장면과 여백을 정한다. 기준과 충돌하면 브리프를 수정하고 의미·구성 변화 시 재승인한다.

## 제작과 검수

- 기획 승인 후 c01·c03·c04용 사진을 각각 신규 생성한다. 원본 카드·경쟁사 화면·다른 실행의 사진은 콘텐츠 자산으로 재사용하지 않는다.
- 로고와 c05 트랙은 [reference manifest](../../../assets/reference/manifest.json)에 기록된 원본 SVG를 참조한다. 문서·자산·원본 Figma는 수정하지 않는다.
- 실제 카드 문구와 캡션은 아래 블록 하나가 기준이다. 텍스트와 로고는 생성 사진에 넣지 않고 HTML/Figma의 별도 요소로 배치한다. 추가 문구나 CTA를 제작 중 임의로 붙이지 않는다.
- 자동 통과 조건: 1080×1350, 카드 5개와 고유 ID·순서 일치, CTA 카드 정확히 1개, 출처 ID 존재, 필수 사진 브리프, 문구에 미해결 표시 없음. 후속 단계에는 사진 출처·승인 버전·HTML 문구·PNG 규격과 장수도 검사한다.
- 사람 판단: 공감 문구의 자연스러움, 페이스 보장처럼 읽히지 않는지, 브랜드 말투와 신규 사진 분위기, 인물 관계와 발끝 크롭, 실제 가독성, CTA의 적절성. 이 단계에서는 문구·브리프만 검토하며 시각적 완성도는 실제 HTML에서 판단한다.
- 승인 순서: 이 기획 승인 → 신규 사진·HTML 제작 및 브라우저 확인 → 별도 프리뷰 승인 → 편집 가능한 새 Figma 파일·PNG·캡션 전달. 게시·예약 발행은 하지 않는다.
