사용 시 종횡비를 유지한다. 로고는 자르거나 재타이핑하지 않는다. 장식은 주제와 구도에 맞게 이동·균등 확대축소할 수 있다. 파생 자산을 만들 때에는 원본 추출 파일을 덮어쓰지 말고 새 파일과 변경 기록을 남긴다.

`evidence/source-section-229-248.png`는 원본 전체의 관찰용 기록이다. 사진과 레이아웃을 포함하지만 완성 콘텐츠용 재사용 자산은 아니다. 사진은 기획마다 새로 제작한다. `evidence/node-properties.json`은 주요 노드의 확인값을 담은 발췌이며 전체 파일 덤프가 아니다.

상세 출처·체크섬은 [manifest.json](manifest.json)에 있다. 만료되는 다운로드 URL 대신 원본 Figma 링크를 기록한다.
